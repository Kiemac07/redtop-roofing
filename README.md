# Redtop Roofing — Website Starter

Multi-page responsive website rebrand based on the information supplied by the previous Buxton Roofing site, rebuilt for the Redtop Roofing brand.

## Pages
- Home
- Services
- Projects
- About
- Contact / Quote

## Included
- Red/white/charcoal visual identity
- Oswald + Inter typography
- Mobile-first navigation and layouts
- Desktop responsive layouts
- Supplied Redtop logo used as brand mark and favicon
- All supplied roofing photos included
- Service information carried across from the old website
- Placeholder contact details where final Redtop details were not supplied
- Basic quote form UI (connect to Formspree/Netlify Forms/backend before launch)
